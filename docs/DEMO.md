# A short Orbit walkthrough

Aim for about 90 seconds. Use the local demo and illustrative tasks, not private account data.

1. **The problem (10 seconds):** “Small projects become harder when deadlines, next steps, and progress are scattered. Orbit keeps them in one personal workspace.”
2. **Today and Upcoming (15 seconds):** Open Today to show overdue work and today's deadlines. Open Upcoming to show the next seven days.
3. **Make a task actionable (20 seconds):** Create a task, set a deadline, and add two checklist steps. Save, then complete one step directly from the card.
4. **Reuse work (10 seconds):** Duplicate the task. Show that its deadline is cleared and its checklist is ready to start again.
5. **See the project (15 seconds):** Open Projects. Explain the progress, overdue count, and next unfinished deadline; open that project's tasks.
6. **Protect focus (10 seconds):** Start the focus timer, pause, and resume. Mention that it survives a refresh in the same browser.
7. **The implementation (10 seconds):** “React powers the workspace, Express validates requests, and MongoDB saves private account tasks. The demo stays in local browser storage.”

Close with the repository link and, after deployment, the verified live URL. Describe this release as a personal workspace; shared team collaboration and recurring tasks are not implemented. Do not claim production performance, security certification, search rankings, or ad revenue without evidence.
